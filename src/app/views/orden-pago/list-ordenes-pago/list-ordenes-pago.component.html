Cargar Órdenes de Pago

Las órdenes que cargue acá quedan pendientes de rendir. Para verlas, rendirlas o darlas de baja, vaya a Rendición de Cuentas.

Importar desde Excel

Para cargar varias órdenes de una vez. El sistema primero revisa el archivo y muestra lo que entendió de cada fila; recién después se confirma. Si una fila tiene error, no se carga ninguna.

Cargar una sola orden

Para una orden suelta, sin armar un archivo. Se llena el formulario y el sistema le asigna el número.
