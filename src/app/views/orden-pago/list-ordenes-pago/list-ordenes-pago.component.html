Importaciones

Todo lo que entra a RENDIX desde afuera. Las órdenes que cargue acá quedan pendientes de rendir; para verlas, rendirlas o darlas de baja, vaya a Rendición de Cuentas.

Maestros

Se cargan una vez al empezar, y después solo cuando el CONCAR cambia.

Anexos
empiece por acá

El maestro de anexos del CONCAR: las personas y las empresas con su código. Sin esto, una orden a nombre de un DNI no se puede cargar y el asiento sale sin anexo en la contrapartida. Acepta el Excel del CONCAR o un archivo de texto.

Parámetros del asiento

La cuenta de gasto de cada tipo de gasto, los parámetros del asiento (subdiario, cuenta de entrega, cuenta de devolución), las equivalencias con CONCAR y el tipo de cambio. Marca en ámbar lo que todavía es una suposición nuestra.

Órdenes de pago

Las entregas a rendir. Es la carga de todos los días.

Importar desde Excel

Para cargar varias órdenes de una vez. El sistema primero revisa el archivo y muestra lo que entendió de cada fila; recién después se confirma. Si una fila tiene error, no se carga ninguna.

Cargar una sola orden

Para una orden suelta, sin armar un archivo. Se llena el formulario y el sistema le asigna el número.
